# Esports Tournament Management System

## Project Overview

The **Esports Tournament Management System** is a full-stack web application designed to simplify the creation and management of esports tournaments. The platform enables tournament organizers to create and manage tournaments while allowing players and teams to register, participate in matches, and track tournament progress.

The project is inspired by popular esports platforms such as Start.gg, Battlefy, FACEIT, Challonge, and Toornament. Rather than cloning these platforms, this project aims to build a modern, scalable, and simplified tournament management system using industry best practices.

---

# Project Objectives

The primary objectives of this project are:

- Build a resume-quality full-stack application.
- Apply real-world software engineering principles.
- Design a scalable and modular architecture.
- Implement secure authentication and authorization.
- Practice REST API development.
- Learn database modeling using MongoDB.
- Develop a responsive and modern React frontend.
- Deploy a production-ready application.

---

# Target Users

The system supports four primary user roles:

- Admin
- Tournament Organizer
- Team Captain
- Player

Additionally, guest users can browse public tournaments before registering.
